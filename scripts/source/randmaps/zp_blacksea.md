# Black Sea

## general
- file format .xs (Age of Empires III)
- description of specific commands: scripts/source/randmaps/all_rm_commands.txt

## Description
- the map uses same size and constraints as game/randmaps/zpdeathsea.sx
- One big lake on the middle of the map on the south there is a water corridor conjoining the lake with the edge of the map
- the map has two possible random variantions: winter and summer
    - winter: snow on the north grass/dirt on the south
    - summer: grass on the north desert on the south
- it means there are 4 terrain types used as a global variable, so these can be changed any time
- map types: water, eastEurope, euroNavalTradeRoute, grass / snow
- Natives: zpCossacks, NatPirates, zpOrthodox
- hunts: Deer
- berry bushes: BerryBush
- mines: MineCopper

### Summer variant
- Sea Type: Baltic Sea

### Winter variant
- Sea Type: Italian Sea

## Player and native placement
- Players are placed around the lake
- Natives: zpCossacks, NatPirates, zpOrthodox
