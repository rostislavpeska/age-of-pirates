# Test scenarios (editor only, never shipped)

Random-map scripts used only to test content in the Scenario Editor. They live here, under `scripts/`,
so the mod never loads or ships them: the release audit (`mod-deploy-check`) leaves `scripts/` out, and the
game only sees a map once it is copied into this device's Steam `Game/RandMaps` folder.

Make a test map visible in the Scenario Editor on a device (once per device; later pulls keep the copy in sync):

```text
python scripts/tools/sync_local_maps.py --top scripts/test_scenarios/<stem>
```

Then: Scenario Editor -> File -> New -> pick the map (row 2 of the Type list). Do not put test maps in
`game/randmaps/` or `randmaps/`: those are mod content.

| Map | Stem | Purpose |
| --- | --- | --- |
| TEST Korean Construction | `zzKoreanConstructionTest` | Pre-built Korean TC, Barracks and Stable (destruction tests: select, Delete) plus three TEST Korean Builder Wagons and resources for player 1 (construction stages, about 3-4 minutes per building). Spine generated by `scripts/tools/unitbench.py` (generator copy in `scripts/maps/`); the marked block at the end is hand-written. |
