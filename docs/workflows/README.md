# AI Workflows for Age of Pirates Modding

This directory contains step-by-step workflows for common modding tasks. Each workflow is designed to be followed by AI agents or human modders to accomplish specific goals without troubleshooting.

## Purpose

- **Standardize complex tasks** - Consistent approach across the project
- **Reduce errors** - Tested procedures with known pitfalls documented
- **Speed up development** - Jump straight to execution
- **Knowledge preservation** - Project-specific patterns captured

## Available Workflows

1. **[creating-spawning-building.md](creating-spawning-building.md)** - Create a building with tactic-based unit spawning (Maintain system)
   - Complete file creation workflow
   - Proto unit, tactics, commands, strings
   - Common pitfalls and solutions

## How to Use These Workflows

### For AI Agents:
1. Read the entire workflow before starting
2. Follow steps sequentially
3. Use the exact code patterns provided
4. Check the "Common Pitfalls" section
5. Validate at checkpoints

### For Human Modders:
- Use as reference guide
- Adapt patterns to your needs
- Check troubleshooting sections when stuck

## Workflow Format

Each workflow contains:
- **Overview** - What you'll create
- **Prerequisites** - What you need before starting
- **File Structure** - All files that will be created
- **Step-by-Step Instructions** - Detailed implementation
- **Code Templates** - Copy-paste ready examples
- **Common Pitfalls** - Known issues and solutions
- **Testing Checklist** - Verification steps
- **Related Workflows** - Connected procedures

## Contributing Workflows

When adding new workflows:
1. Use existing format as template
2. Test the workflow completely
3. Document all pitfalls encountered
4. Include code examples
5. Add validation steps
